# PARA Method — Detailed Guide

The PARA method (by Tiago Forte) organizes all information into four categories based on **actionability**, not topic.

## The Four Categories

### 0-Inbox (Capture)
Everything starts here. No filtering, no organizing — just capture.
- Quick ideas and thoughts
- Links, articles, bookmarks
- Meeting notes before processing
- Voice memo transcriptions
- Screenshots and images

**Rule:** Process inbox at least weekly. Nothing lives here permanently.

### 1-Projects (Active, time-bound)
A project has:
- A **goal** (clear definition of done)
- A **deadline** (even if self-imposed)

Examples:
- "Launch company website" (done = site is live)
- "Write Q1 report" (done = submitted)
- "Plan vacation to Japan" (done = trip booked)

**Move to Archive when complete.**

### 2-Areas (Ongoing, no end date)
An area is a sphere of activity requiring ongoing maintenance.

Examples:
- Health & Fitness
- Finances & Investments
- Career Development
- Home Maintenance
- Relationships
- Side Projects (ongoing)
- Learning & Education

**Never "done" — review monthly for neglected areas.**

### 3-Resources (Reference, by topic)
Useful information organized by topic or interest.

Examples:
- Book notes and summaries
- Article highlights
- How-to guides
- Code snippets
- Recipes
- Travel guides
- Tool configurations

**Organize by topic, not by source.**

### 4-Archive (Inactive)
Completed projects, abandoned ideas, no-longer-relevant resources.

Examples:
- Finished projects (move the whole folder)
- Old area notes you no longer maintain
- Outdated resource collections
- Past meeting notes

**Searchable but out of the way. Never delete — archive.**

## Decision Flowchart

```
New note arrives in Inbox
    │
    ├── Is it actionable?
    │   ├── Yes → Is there a deadline/goal?
    │   │         ├── Yes → 1-Projects
    │   │         └── No → 2-Areas
    │   └── No → Is it useful reference?
    │             ├── Yes → 3-Resources
    │             └── No → Delete or 4-Archive
    │
    └── Not sure? Leave in Inbox, revisit next review
```

## Weekly Review Process

1. **Process Inbox** (15 min)
   - Go through every note in `0-Inbox/`
   - Move each to the correct PARA folder
   - Delete anything no longer relevant

2. **Review Projects** (10 min)
   - Is each project still active?
   - Update status/tasks
   - Archive any completed projects

3. **Scan Areas** (5 min)
   - Any area being neglected?
   - Create a project if action is needed

4. **Quick Archive sweep** (5 min)
   - Move stale items from Projects/Areas to Archive
